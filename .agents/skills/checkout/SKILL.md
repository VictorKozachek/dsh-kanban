# /checkout — конец рабочего дня

1. Запусти:
   ```bash
   bin/checkout.sh
   ```
   По умолчанию checkout пушит уже закоммиченные ветки (`--no-push` отключает).
   Грязные файлы не коммитит — они остаются причиной «нельзя».
2. Если ты manager — разошли наряд checkout оркестраторам: завершить/зафиксировать
   незавершённое, закоммитить, запушить, синхронизировать карточки с трекером,
   ответить одной строкой. Собери подтверждения; неответивших отметь.
3. Проверь итог: нет незакоммиченных файлов, нет незапушенных коммитов, нет
   `blocked`, карточки совпадают с трекером (если трекер настроен).
4. В конце выдай **отдельным сообщением** явный вердикт:
   - **«Можно выключать компьютер»** — всё чисто;
   - **«Выключать пока нельзя: …»** — со списком причин.
   Отчёт — в `.kanban/.checkout/<date>.md`.

Ограничения: не делай force-push; не коммить чужие грязные файлы; не скрывай
блокеры и неответивших.
