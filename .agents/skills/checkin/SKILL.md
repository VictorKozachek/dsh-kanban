# /checkin — начало рабочего дня

1. Запусти фактическую базу:
   ```bash
   bin/checkin.sh
   ```
   Скрипт прочитает `.kanban/tasks`, покажет «сделано с прошлого раза», в работе,
   todo, блокеры и спящие todo; отчёт запишется в `.kanban/.checkin/<date>.md`.
2. Если ты manager — разошли наряд checkin оркестраторам (по карте ролей/доскам)
   и попроси ответ формата:
   `<компонент> | вчера: … | сегодня: <ID, ID> | блокеры: … | спящие: …`.
3. Собери ответы в отчёт; неответивших отметь отдельно, не выдумывай статусы.
4. Верни человеку короткую сводку: сделано / берём сейчас / блокеры и почему /
   что нужно от человека. Полный отчёт — в файле.

Ограничения: не двигай карточки вместо оркестратора; не запускай больше 3 задач
в работу; если очередь пуста — скажи «нужна декомпозиция», а не выдумывай задачи.
