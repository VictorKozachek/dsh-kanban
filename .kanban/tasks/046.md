## Задача

Скрипт асайна конкретной карточки на «самого свободного» исполнителя — механика
под фичу 002 (человек тащит карточку из `backlog` в `todo`, асайн делает хост).
Основание: `.kanban/specs/002.md`, разделы «Решения» и «Архитектура».

### `bin/task-assign.sh <id> [--dry-run] [--unassign]`

Режим асайна (по умолчанию):
- найти карточку по слитому снимку доски — та же семантика, что у
  `backlog-fill.sh` (основной чекаут + `worktrees/*` + `.worktrees/*`, свежесть
  `updated`, из дерева только одноимённая карточка, `liveId`); запомнить, **где
  лежит** карточка (main или конкретное дерево) — переход и коммит делаются там
  же через `bin/task-move.sh`;
- карточка должна быть в `backlog`, иначе отказ (код 3, внятный текст);
- пул — `.kanban/.workers.json` (порядок = приоритет), fallback — `worker` из
  `.kanban/.watcher-roles.json`;
- нагрузка исполнителя = число карточек с этим `owner` в статусах
  `in-progress + in-review + testing` по слитому снимку; «занят» = есть
  `in-progress` (такому асайн не делаем);
- среди свободных — минимальная нагрузка, равенство решает порядок пула;
  свободных нет — код 4 и «все заняты» (карточка остаётся в `backlog`);
- перевод: `bin/task-move.sh <id> todo --owner <session> --role worker`
  (никаких ручных правок front matter).

Режим `--unassign`:
- карточка должна быть строго в `todo` (не в `in-progress` и не дальше) —
  иначе код 3 и «карточку уже взяли в работу / она не в очереди»;
- перевод `todo → backlog` (владелец и роль снимаются правилами `task-move.sh`).

`--dry-run` печатает план (карточка, где лежит, текущий статус, таблица нагрузок,
выбранный исполнитель/отказ) и **ничего не меняет**. Коды: 0 — ок, 1 — конфиг или
доска, 3 — карточка не найдена/не тот статус, 4 — нет свободных.

### Тесты (`bin/test-scripts.sh`, блок по образцу `backlog-fill`)

- нагрузка: у w1 одна карточка в `testing`, у w2 пусто → выбирается w2; при
  равенстве — первый по `.workers.json`; занятый (`in-progress`) не выбирается;
  у всех `in-progress` → код 4, карточка не изменилась;
- выбор среди свободных идёт по нагрузке, а не по порядку пула (w1 свободен с
  нагрузкой 2, w2 свободен с 0 → w2);
- карточка в рабочем дереве: асайн и коммит `kanban(<id>): todo` в ветке,
  основной чекаут не тронут;
- `--unassign`: `todo` без владельца/с владельцем → `backlog`, владелец и роль
  пустые; из `in-progress` — код 3, карточка не изменилась;
- `--dry-run` — ни одного изменения (сверка хешей файлов и `git status`);
- fallback пула на `.watcher-roles.json`; битый `.workers.json` — код 1.

Файлы задачи: `bin/task-assign.sh` (новый), `bin/test-scripts.sh`. Не трогать:
`dsh-kanban/`, `AGENTS.md`, `KANBAN.md`, чужие карточки.
