## Задача (issue #4, протокол)

Два писателя в одном worktree: вторая сессия правила те же файлы, «file changed
since it was read». `task-move` проверяет owner только при взятии/снятии
блокировки, параллельная работа не обнаруживается.

### Состав

- Lock-файл `.kanban/.locks/<id>.json`: `{ sessionId, worktree, since, heartbeat }`.
- `task-move <id> in-progress` берёт/продлевает lock; вторая сессия получает
  отказ с понятным текстом (и кто держит).
- `in-review`/`testing`/`ready` освобождают lock после перехода (или по TTL).
- Просроченный lock (нет heartbeat N минут) можно снять `--force`.
- В наряде отдавать «замок»: owner + время выдачи.
- Тесты: второй писатель отклонён; TTL; force.

### Критерии

- [ ] Две сессии не могут одновременно вести одну карточку в одном worktree.
- [ ] Lock виден в карточке/наряде; просроченный снимается.
- [ ] `bin/test.sh` зелёный.
