## Задача

Пользователь хочет, чтобы работа начиналась сама при старте приложения.
Реализован автостарт: на холодном старте плагин читает `.kanban/autostart.json`
и отправляет в указанные сессии prompt «начинай по плану» (очередь, как наряд).

## Готово

- `dsh-kanban/lib/autostart.js`: `notBefore`, `oncePerDay`, список сессий,
  текст; состояние `$DSH_HOME/kanban-autostart.json`; prompt с таймаутом.
- В `apply`: только на холодном старте (`uptime <120 c`), не на HMR; ошибки
  в диагностику `autostart-sent/failed`.
- `.kanban/autostart.json` — локальный (в `.gitignore`), не едет в git.
- Тесты `autostart.test.mjs` (5): нет конфига, notBefore, один раз в день,
  следующий день, невалидная сессия. Полный набор 553.
- Настроен на 20.11 00:00 (+03): в этой сессии начнёт с #089 → #086 → #087 →
  #088 → #073 → #090.

## Ограничение

Срабатывает только на холодном старте приложения; если приложение не
перезапускали, prompt не появится. Файл можно править/выключать.
