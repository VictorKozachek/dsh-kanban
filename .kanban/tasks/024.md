## Задача
Два генератора макета описывают одну и ту же доску по-разному (всё это
pre-existing с `9c213a0`, найдено при проверке #007):

- HTML не рисует значок «в ветке» (`branchBadge` при `source === worktree`), а PNG
  рисует его семь раз — верхняя строка HTML менее тесная, чем PNG;
- формат `updated` разный: PNG «23.09 15:40», HTML — ISO (как плагин);
- тексты заметок карточек 004/005 в двух списках `CARDS` расходятся;
- painter разбирает расход через `int()`, плагин и HTML — через JS `Number()`:
  `tokens: 1e3`, `1.5`, `0x10`, `1e9` рисуются в плагине и HTML, но не в PNG;
- `build-mockup.mjs` в комментарии обещает выход `board-mockup.html`, фактический
  выход — `board-mockup-<вид>-<тема>.html`.

## Критерии готовности
- [ ] у макета один источник данных о карточках (или проверка, что оба списка
      совпадают)
- [ ] состав верхней строки карточки совпадает у HTML и PNG, включая значок
      «в ветке»
- [ ] формат `updated` один и тот же — и тот же, что показывает плагин
- [ ] разбор расхода одинаков: `int()` и `Number()` дают один результат на
      `1e3`, `1.5`, `0x10`
- [ ] комментарий про выход соответствует факту
- [ ] `bin/test.sh` зелёный
