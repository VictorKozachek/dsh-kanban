## Задача
В GUI не было видно ни одного пресета роли. Причина: в DSH 0.1.7 пресет — это
**строка композиции профиля** (`@deepseek-ai/dsh-agent-preset` с
`config.id/order/plugins`), а старый формат каталогом `~/.dsh/.agent-presets`
эта версия не читает вовсе. `bin/install-presets.sh` писал именно старый формат,
поэтому четыре роли лежали в каталоге, до которого приложению нет дела.

## Критерии готовности
- [x] четыре пресета ролей есть в композиции desktop-профиля (проверено офлайн:
      строки `preset-dispatcher/worker/reviewer/verifier`, порядок 10–13, по 19
      плагинов, персона наша, 0 предупреждений композиции)
- [x] генерация и установка воспроизводимы скриптами, без ручных правок
- [x] `bin/test.sh` зелёный в `awg` и в `m-future`
- [x] коммиты: `awg` 5d2d6f4, `m-future` 21f23fa
- [ ] проверить глазами в GUI: пресеты видны при создании сессии

## Что поправить (вернул ревьювер)
- [ ] тестовая фикстура пресетов — урезанная заглушка (21 строка) вместо боевого
      шаблона (146 строк): регрессии не заметят смены его формы
- [ ] установщик печатает трейсбек Python, когда песочница запрещает запись в
      патч-слой — нужна понятная строка

Что сделано:

- `bin/gen-role-presets.sh` — собирает строки ролей из встроенного
  `standard.patch.yml`: клонирует строку, подменяет персону из
  `agent-presets/<роль>/persona.txt` и `name`/`description` из `preset.yml`,
  сохраняя `!!js`-условия; результат — `presets/role-presets.patch.yml`.
- `bin/install-presets.sh` — ставит эти строки управляемым блоком в
  `~/.dsh/profiles/<профиль>/cordis.patch.yml` (туда же пишет Web-редактор
  пресетов в этой версии); идемпотентно, есть `--dry-run`, `--profile`,
  `--profiles-dir`, `--rows`.
- `test/fixtures/standard.patch.yml` + регрессии: четыре строки, персона на
  месте, `!!js` сохранены, установка, идемпотентность, отказ на несуществующем
  профиле.
- KANBAN.md: таблица файлов и список проверок.

Хвосты:

- старые каталоги `~/.dsh/.agent-presets/*` этой версией больше не читаются —
  можно удалять (или оставить как историю);
- установщик печатает трейсбек Python, если файловая песочница запрещает запись
  в патч-слой (профиль вне рабочей директории сессии) — стоит заменить на
  понятное сообщение;
- интерфейс установщика изменился: прежние `--target`/`--standard` у него
  больше нет, теперь `--profile`/`--profiles-dir`/`--rows`.
