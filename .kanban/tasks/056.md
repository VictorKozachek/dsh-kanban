## Задача

Под DSH 0.2.1 приложение запускает окружение с `LANG=C.UTF-8`, и на системном
macOS bash 3.2 это ломает `bin/task-assign.sh`: падает на строке
`label="#$ID${title:+ «$title»}"` (мультибайт « сразу после `:+` — bash 3.2
считает байт UTF-8 частью имени переменной: `title?: unbound variable`).
Проверено минимально: `LANG=C bash -c '…${title:+ «$title»}…'` работает,
`LANG=C.UTF-8` — падает. Именно поэтому GUI писал «перенесено», а карточка не
двигалась.

Вторая часть бага — **маскировка кода возврата**: при падении скрипт выходит с
кодом **0**. Причина — `cleanup()` в EXIT-ловушке (`trap cleanup EXIT`, ~строка
348) заканчивается `return 0`: при ошибке статус затирается, а канал асайна
(`dsh-kanban/lib/card-actions.js`) считает `exit 0` успехом. Пользователь видит
«перенесено», карточка остаётся в backlog.

### Репро

```bash
LC_ALL=C.UTF-8 bin/task-assign.sh 055 --dry-run   # ошибка unbound variable, код 0 (!)
LC_ALL=C        bin/task-assign.sh 055 --dry-run   # работает
LC_ALL=C.UTF-8 bash -c 'set -u; t=x; l="#${t:+ «$t»}"; echo ok'   # падает
```

### Что сделать

1. `bin/task-assign.sh`: убрать мультибайт из подстановки — например,
   `label="#$ID"; if [[ -n "$title" ]]; then label="$label «$title»"; fi`
   (или `printf` без `${:+ «…»}`). Проверить, что вывод не изменился.
2. **Аудит всех `bin/*.sh`** на тот же класс: мультибайт (или иной не-ASCII)
   внутри `${var:+…}`, `${var:-…}`, `${var:?…}` и рядом с ними. Сейчас грепом
   найдено одно место (task-assign:370), но пройти все скрипты, чтобы класс не
   повторился; если шаблон полезен — ввести helper.
3. **Код возврата**: EXIT-ловушка не должна затирать статус. Сделать
   `cleanup`, сохраняющую `$?` и возвращающую его (`trap 'code=$?; cleanup; exit
   $code' EXIT` — проверить под bash 3.2, что при ошибке код не 0), и убедиться,
   что другие скрипты с `trap … EXIT` (проверить `bin/`) не имеют той же
   проблемы.
4. **Регрессия в `bin/test-scripts.sh`**: прогонять критичные скрипты
   (`task-assign`, `backlog-fill`, `task-move`, `board-status`, `task-new`) под
   `LANG=C.UTF-8`/`LC_ALL=C.UTF-8` и `C` — коды и вывод совпадают; отдельная
   проверка: `task-assign` на заведомо ошибочном сценарии возвращает **не 0**
   (например, несуществующая карточка → 3, все заняты → 4). Прогонять под
   `/bin/bash` 3.2, без внешних зависимостей.

Файлы задачи: `bin/task-assign.sh`, при необходимости другие `bin/*.sh`
(технические правки локали/ловушек), `bin/test-scripts.sh`. Не трогать:
`dsh-kanban/lib/*` (канал — отдельная задача #057), `KANBAN.md`, `AGENTS.md`.
