## Задача (issue #4, второй симптом)

Сессия активна/мертва, а карточка висит часами в `in-progress`/`in-review`/
`testing`: доска не знает, что роль не работает.

## Готово

- `dsh-kanban/lib/stale.js` — поиск стоящих карточек (порог `minutes`), проверка
  сессии по логу: свежий открытый ход = работает (молчим), хода нет = напоминание
  роли, лога нет = эскалация диспетчеру.
- `runStaleWatchdog` в `apply`: первый проход через 5 с, дальше раз в 10 минут;
  снимается на dispose.
- Анти-спам: `.kanban/.watcher-stale.json` по `cardId:status:updated`.
- Диагностика: `stale-notice`, `stale-escalated`, `stale-skipped`.
- Конфиг `stale: { enabled: false, minutes: 120, maxPerRun: 5, workingMinutes: 15 }`
  (по умолчанию выключено, чтобы не будить старые доски).
- Тесты `stale.test.mjs` (5): мёртвая сессия → диспетчер без повтора; закрытый ход
  → напоминание; работающая сессия → skip; свежая карточка; выключение.
- Полный набор: 523 проверки, зелёный.
