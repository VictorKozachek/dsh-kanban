## Задача
Правило «нераспределённую карточку не берут» держалось только протоколом.
`bin/task-move.sh` теперь отказывает в переходе `todo` → `in-progress`, если
`owner` пуст, указывает на другую сессию или исполнитель не назван вовсе.
Обход — `--force`; сообщение отказа печатает готовую команду закрепления.

## Критерии готовности
- [x] карточка с `owner: ""` не берётся, отказ с понятным сообщением
- [x] карточка, закреплённая за другим id, не берётся
- [x] владелец берёт свою карточку без `--force`
- [x] `--force` выполняет переход (осознанный обход)
- [x] регрессии: без `--owner`, незакреплённая, чужак, `--force`
- [x] документация согласована: `.kanban/tasks/README.md`, `AGENTS.md`,
