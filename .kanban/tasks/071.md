## Задача (M0)

Скелет Rust-хаба: сервис, схема, auth, API, тесты, Docker.

## Готово (18.11)

- `hub/` — Rust (axum 0.8 + rusqlite, SQLite), `Cargo.lock`, Dockerfile,
  `docker-compose.yml`.
- Схема: `instances(project, instance, user, last_seen)`, `cards(project, id,
  rev, payload, assignee, lease_*, updated_at)`.
- API: `/healthz`; heartbeat инстанса; `GET cards?since=`; `POST claim`,
  `release`, `handoff`; `PUT card` (upsert с `base_rev`, CAS).
- Lease: TTL 30 мин (`KANBAN_HUB_LEASE_TTL_SECONDS`), claim/release, истёкший
  lease можно перехватить; чужая/устаревшая запись → 409.
- Auth: Bearer-токен (`KANBAN_HUB_TOKEN`, по умолчанию dev-token).
- Тесты: 5 (`cargo test`): auth/health, lease/CAS, expired lease, list.
- Smoke: `cargo run` + curl — health/create/list работают.
