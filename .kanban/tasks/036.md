## Задача
Карточки в колонке `merged` должны иметь зачёркнутое название задачи: сразу видно, что
работа закрыта.

## Критерии готовности
- [x] название карточки со статусом `merged` рисуется зачёркнутым
- [x] остальные колонки не изменились
- [x] проверка в `dsh-kanban/test/render.test.mjs`, `bin/test.sh` зелёный

## Заметки
Клиентская половина, нужен только F5 (см. «Границы» в KANBAN.md).

## Сделано

- в `client.js` добавлен стиль `cardTitleMerged` (`line-through` плюс приглушённая
  непрозрачность), название карточки выбирает стиль по статусу: `merged` — зачёркнуто,
  остальные колонки как были;
- в `render.test.mjs` появился обход стилей (`collectStyles`) и проверка: зачёркнуто
  ровно одно название — карточки в `merged` (в фикстурах она одна). Обход по стилям, а
  не через `collectAttrs`: тот приводит значения к строке и для объектов стилей не
  годится;
- правка только в клиентской половине, поэтому для проверки хватит F5 (см. «Границы»
  в KANBAN.md).
