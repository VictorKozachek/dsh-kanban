## Задача

Репозиторий `dsh-kanban` — теперь единственный источник правды: набор больше не
разрабатывается в проекте `awg` и не переносится оттуда. Старая привязка осталась
в коде и тестах: `bin/sync-from-awg.sh` сверяет копии с `~/projects/awg`, и его
`--check` — единственная красная проверка `bin/test.sh` на этой машине
(«набор расходится с источником …; перенесите правки: bin/sync-from-awg.sh»).

Директива: разрабатываем плагин только в текущей папке, внешних зависимостей быть
не должно.

### Что сделать

1. **Удалить** `bin/sync-from-awg.sh`.
2. **Убрать из `bin/test-scripts.sh`** всё, что про синхронизацию:
   - секцию `== синхронизация набора: перенос, удаление, --check` (~строка 1476)
     и всю её подготовку (`$sync_src`, `$sync_dst`, копии скрипта, проверки
     `--from`, `--check`, коды возврата, «другое состояние источника»);
   - секцию `== набор совпадает с проектом-источником` (~строка 1711) — это и есть
     зелёная только при совпадении копии проверка;
   - блок «Сверка не должна краснеть из-за чужой незакоммиченной работы в
     источнике (#034)» (~1647–1710): он использует `sync-from-awg.sh` и копии в
     `$dirty_src/$dirty_dst` — удалить вместе с фикстурами, оставив проверку
     «таблица файлов не отстаёт от набора» целой.
3. После удаления в репозитории **не должно остаться** упоминаний:
   `grep -rn "sync-from-awg\|projects/awg\|DSH_KANBAN_SOURCE" bin/ test/ dsh-kanban/ .agents/ presets/`
   — пусто. (`KANBAN.md`, `AGENTS.md`, `FEATURES*.md` не трогать — их обновит
   оркестратор после слияния.)
4. `bin/test-scripts.sh` должен остаться цельным: без «висячих» переменных и
   temp-каталогов, с прежними секциями и их именами; удалять только
   синхронизацию, не ломая соседние проверки (`таблица файлов`, `дамп доски`,
   `пресеты`, `node.sh`, `install-kanban`).

Файлы задачи: `bin/sync-from-awg.sh` (удалить), `bin/test-scripts.sh`.
Не трогать: `KANBAN.md`, `AGENTS.md`, `FEATURES.md`, `FEATURES.ru.md`,
`dsh-kanban/lib/*`, `.kanban/` (кроме своей карточки).

## Критерии готовности

- [ ] `bin/test.sh` — **полностью зелёный, 0 провалов** (впервые: внешней сверки
      больше нет), painter и все node-наборы проходят.
- [ ] `bin/test-scripts.sh`, запущенный отдельно, проходит; в его выводе нет
      секций про синхронизацию.
- [ ] `grep` из пункта 3 пуст; `ls bin/sync-from-awg.sh` → нет файла.
- [ ] Ни один другой скрипт/тест не ссылается на удалённый файл.
- [ ] В заметке — новое число проверок набора (для обновления документации
      оркестратором).
