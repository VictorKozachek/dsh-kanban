## Задача (issue #4)

После рестарта DSH сессии с прерванным ходом остаются мёртвыми («Task stopped»).
DSH при `resume` сам досыпает `interruptedTurnClosers`, поэтому достаточно
**на старте найти такие сессии и отправить prompt**.

## Готово

- `dsh-kanban/lib/session-log.js` — чтение лога сессии: `splitFrames`, `decodeLog`,
  `openTurnOf`, `lastTurnStartSeq`, `lastEventTime`, `lastToolName`.
- `dsh-kanban/lib/resume.js` — поиск прерванных сессий по картам ролей, окно
  возраста (`minAgeSeconds`…`maxAgeHours`), лимит `maxSessions`, prompt-возврат
  в очередь, дедуп `.kanban/.watcher-resume.json` по `sessionId + turnStartSeq`,
  диагностика `resume-sent/skipped/failed`.
- В `apply` — только на **холодном старте** (`process.uptime < 120 c`), не на HMR;
  асинхронно, не блокирует запуск сторожа.
- Настройка `resume: { enabled=true, maxAgeHours=12, minAgeSeconds=60, maxSessions=5 }`.
- Текст наряда: ход прерван, проверить незавершённые tool calls, не повторять
  вслепую, продолжить по карточке/роли; «вопрос снят при перезапуске».
- `.kanban/.watcher-resume.json` добавлен в `.gitignore` и шаблон `kanban-init`.
- Тесты `resume.test.mjs` (6): поиск открытого хода, окно возраста, дедуп,
  выключение, ошибка prompt, `openTurnOf`. Полный набор: 518 проверок, зелёный.

## Ограничения

- Сессии без карты ролей не будим (осознанно).
- Если ход был слишком свежим (< minAgeSeconds), в этот старт не будим;
  следующий старт подхватит (или можно уменьшить порог).
- Stale-watchdog (#078) и lock (#079) — отдельно.
