## Задача

Вторая часть фикса issue #1 (спека `.kanban/specs/005.md`): миграция профиля и
документация. Основной код («пресеты регистрирует плагин при старте») — #062;
эту задачу делать **после** его слияния (id и формат JSON зафиксируются кодом).

### Что сделать

1. **`bin/install-presets.sh --takeover`** — убрать legacy-блок пресетов из
   профильного патча (`~/.dsh/profiles/<профиль>/cordis.patch.yml`), когда
   определения уже поставляет плагин: строки между маркерами блока удаляются,
   повторный запуск идемпотентен, без `--takeover` — прежнее поведение
   (для старых версий DSH/совместимости). Если профильный блок одновременно
   есть и в плагине — после takeover предупреждений о дубликатах в логе нет.
   Проверять на временном профиле (temp dir), не на живом.
2. **Регрессии в `bin/test-scripts.sh`**: takeover удаляет блок и не трогает
   остальной патч; повторный запуск идемпотентен; профиль без блока —
   «нечего убирать», код 0; предупреждение/подсказка при отсутствии маркеров.
3. **Документация.**
   - `KANBAN.md`: раздел «Обновление плагина и пресеты» — id пресетов
     (`dispatcher/worker/reviewer/verifier`) стабильны, определения едут вместе
     с плагином и регистрируются при старте, legacy-строки в профиле больше не
     нужны (`--takeover`), сессии после обновления не требуют пересоздания;
     чеклист обновления DSH: `bin/gen-role-presets.sh` (в составе релиза) →
     `bin/install-kanban.sh` при необходимости → рестарт.
   - `AGENTS.md`: коротко — никогда не переименовывать id пресетов, генерировать
     пресеты в составе плагина.
   - `FEATURES.md` / `FEATURES.ru.md` и `README.md`: самовосстановление пресетов,
     сессии не требуют пересоздания; числа проверок.
4. **Миграционная инструкция для уже сломанных пользователей** (в `KANBAN.md`,
   «Диагностика»): сессии «стали стандартными» после обновления → обновить плагин
   до версии с самолечением и перезапустить профиль; если ставили пресеты
   вручную — `bin/install-presets.sh --takeover`; архивировать сессии **не
   нужно** (id в логах сохранён).

Файлы задачи: `bin/install-presets.sh`, `bin/test-scripts.sh`, `KANBAN.md`,
`AGENTS.md`, `FEATURES.md`, `FEATURES.ru.md`, `README.md`.
Не трогать: `dsh-kanban/lib/*` (это #062), `.kanban/` (кроме своей карточки).
