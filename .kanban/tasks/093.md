## Тестовый план (согласован 23.11)

1. **Postgres**: миграция SQLite → Postgres, одинаковые API-тесты на обеих БД.
2. **Два инстанса**: Алиса создаёт карточку → Боб claim → правка → release; конфликт lease даёт 409.
3. **Падение хаба**: kill -9, поднять, клиенты догоняют по курсору, lease истекает, карточка не теряется.
4. **Restore**: snapshot → новый hub → карточки/rev/lease восстановлены.
5. **Нагрузка**: 4 клиента, 100 карточек, 1000 операций; p95 latency, отсутствие 5xx.
6. **HA**: standby/реплика, переключение, отсутствие split-brain (или явное решение, что HA вне MVP).

Критерии: тест воспроизводим одной командой (docker compose + скрипт), результаты в отчёте.
