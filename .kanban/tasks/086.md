## Задача (на 19.11)

Новая роль **manager** — менеджер над оркестраторами, не оркестратор. Пользователь
общается лично с ним и видит картину по проекту.

Обязанности:
- управляет оркестраторами (диспетчерами), следит за соблюдением плана работ;
- запускает рабочий день (`/checkin`), закрывает (`/checkout`);
- собирает и формирует отчёты пользователю: сделано/план/блокеры;
- эскалирует застрявшие карточки/сессии, не подменяет оркестратора.

Решения:
- отдельный пресет `manager` (order 9, до dispatcher=10), не роль доски:
  наряды по карточкам остаются у dispatcher/worker/reviewer/verifier;
- пока на текущих проектах роль можно исполнять существующей сессией
  dispatcher (временно, до появления manager-пресета);
- иерархия: пользователь → manager → dispatcher(ы) → роли задач.

Что сделать:
1. `agent-presets/manager/{persona.txt,preset.yml}` — управление, отчёты,
   протоколы дня, запрет писать код/мержить.
2. Генератор `bin/gen-role-presets.sh`: + manager; артефакты (6 пресетов);
   `ROLE_IDS` в `lib/presets.js`; тесты/доки.
3. Решить, нужен ли manager в карте ролей доски (сейчас роли доски — 4);
   вероятно, manager читает доски всех проектов и общается с dispatcher.
4. Связать с #087 (checkin) и #088 (checkout).

Критерии: пресет manager доступен после рестарта; может собрать отчёт по
нескольким доскам; не двигает карточки вместо оркестратора.
