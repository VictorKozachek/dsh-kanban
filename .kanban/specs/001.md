# Kanban hardening: бриф эксплуатации AI-Factory (27.11.2026)

Источник: документ заказчика по итогам эксплуатации ~90 досок, 1000+ карточек,
роли dispatcher/worker/reviewer/verifier, синк с YouTrack.

## Факты, которые ломались

1. Затирание общего `.kanban`/BOARD чужими сессиями.
2. Неизвестный статус (`review`) молча рендерился как `backlog`.
3. Потеря метаданных BOARD (владелец `—`, заголовок `BOARD — .`).
4. `.watcher-roles.json` расходился с пресетами сессий.
5. Watcher state перезаписывался и возвращал старые ключи.
6. Артефактные клоны (`.build`, `.worktrees`, `target`, `.review-*`) считались карточками.
7. Карточки удалялись физически вместо архива.
8. Наряды не доходили; `agent-busy` считался сбоем.
9. `task-move` оставлял грязное дерево.
10. Гонки двух агентов на одной карточке (merged→ready).
11. Дубли карточек из копий `.kanban`.
12. Нет событий/метрик и внешнего API.

## Требования MVP

1. Single-writer lock на `.kanban`/BOARD: pid/session, crash-safe; чужая запись — ошибка.
2. Единый словарь статусов: `backlog|todo|in-progress|in-review|testing|ready|merged|blocked|dropped`; unknown — ошибка.
3. Честный BOARD: владелец/заголовок/счётчики из карточек.
4. Архив вместо удаления: `.kanban/archive/`, причина, «переименована из».
5. Игнор артефактов: `.build/**`, `.worktrees/**`, `worktrees/**`, `target/**`, `.review-*`.
6. Роль-карта из пресетов, warning при расхождении.
7. Watcher state: версия, TTL, атомарная запись, не затирать новые ключи.
8. Доставка: `prompt` + ретраи; `agent-busy` — не fail; fallback файловая очередь.
9. Move: карточка + BOARD атомарно, чистый tree/авто-коммит.
10. События/метрики: JSON-лог кто/что/когда, счётчики, детект затирания.
11. Внешний API: list/move/commit/validate, идемпотентность по id.
12. YT-хуки: merged → State=Done/tracker, предупреждение о расхождении.

## План

MVP: статусы, single-writer + atomic move, архив, ignore артефактов, watcher state,
роль-карта, доставка busy/retry.
Phase 2: BOARD-метаданные/снапшоты, события/метрики, внешний API, YT-хуки.

## Границы ответственности (уточнено 27.11)

В скоуп входит **только плагин Kanban**: карточки/BOARD, статусы, роли и доставка
нарядов, блокировки записи, архив, игнор артефактов, watcher state, API/метрики
канбана и его документация.

Вне скоупа:
- `dsh-memory` (память, поиск, инъекции) — отдельный воркспейс;
- OOM/сборки/`CARGO_TARGET_DIR`/`TMPDIR`/диск/лимиты hot-сессий — общехостовые
  правила эксплуатации, не код плагина;
- бюджет токенов и «чтение файлов окнами» — правила DSH, не канбан;
- хостинг/Postgres/HA — #093.
